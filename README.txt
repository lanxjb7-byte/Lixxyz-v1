Lixxy V1 - Floating Panel Plus
================================

Additional floating panel tools:
- SCREENSHOT: uses Android MediaProjection consent; saves PNG to Pictures/Lixzzy.
- RECORD SCREEN: uses Android MediaProjection consent; saves MP4 under Android/data/com.lanxx.ffpanel/files/Movies/Lixzzy. Press STOP RECORD to finish.
- PEMBERSIHAN MEMORI: shows RAM statistics and opens app settings. Android does not let ordinary apps forcibly clear another app's RAM.
- TAMBAHKAN APK / APLIKASI: adds a shortcut to an installed app in the floating panel. It does not install APK files.
- Existing OPEN APLIKASI KE-2 and other utility items remain.

Permissions:
- Display over other apps
- Usage access
- Android screen-capture consent each time screenshot/record starts

Access key demo: LAX-YSK-02HA
Upload the CONTENTS of this ZIP to the root of the GitHub repository.
Workflow: .github/workflows/android.yml

Notes:
- Screen recording captures screen video only (no microphone audio).
- Some games or Android versions may restrict overlays or capture protected content.
- Drag HS, Headlock, Aim Perfect are display-only labels, not gameplay modifications.

Network controls added:
- NYALAKAN WIFI: opens Android Wi-Fi panel/settings.
- DATA SELULER: opens Android Internet connectivity / mobile network settings.
- HOTSPOT: opens Android tethering/hotspot settings when available.
- BLUETOOTH: requests enable on older Android versions or opens Bluetooth settings on Android 13+.
Android restricts ordinary apps from silently toggling mobile data, hotspot, and (on newer versions) Wi-Fi/Bluetooth. The buttons use Android's own controls and may vary by device manufacturer.


FITUR BARU:
- MODE SENYAP memakai akses khusus Jangan Ganggu Android. Berikan izin dari halaman akses Jangan Ganggu yang terbuka. Efek panggilan/notifikasi mengikuti pengecualian dan aturan sistem.
- GAME SPACE menyediakan tema RINGAN (hijau), SEIMBANG (biru), dan EKSTREM (merah-hitam). Pilihan mengubah warna jendela mengambang saja; tidak mengubah performa/FPS game.
